## Deployment Instructions

### Google AI Studio to GitHub
This application was generated using Google AI Studio App Build. The source code was pushed directly to this approved GitHub repository using the built-in AI Studio GitHub connection. 

### Cloudflare Pages Deployment
This app is deployed using Cloudflare Pages. 
* **Deployment Method:** Connected via GitHub repository integration.
* **Framework Preset:** Vite
* **Build Command:** `npm run build`
* **Build Output Directory:** `dist`
